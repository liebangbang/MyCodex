核心能力

一个客户端，干完 AI 该干的活

不是又一个网页聊天框。MyCodex 把对话、视觉、工具、文件管理收进同一个桌面窗口。

多模型路由

按任务选模型：文字活儿用便宜的 DeepSeek，看图用通义千问视觉模型。你只管选，端点自动切换。

视觉理解

多图上传即识别，简历截图、海报、官网截图直接丢进去就能分析；无视觉模型时本地 OCR 兜底。

多任务管理

新建、切换、搜索、折叠任务列表；关掉再打开自动恢复到上次进度，长项目不断档。

产物即时预览

右侧直接渲染生成的网页、Markdown、文本；链接可点开。HTML 自动内联资源，所见即所得。

本地工具执行

读本地文件、跑命令、产出文件，全程在桌面内完成。危险操作二次确认，防误删误改。

隐私优先

配置与对话留在本地，密钥文件权限锁到 600；不上传裸数据，合规风险低。

为什么本地优先

把 AI 装进自己的电脑，
而不是别人的服务器

  • ✓
    敏感资料不外传简历、JD、合同、薪酬——这些本就不该进第三方服务器的数据，全程在本机处理。
  • ✓
    断网也能续上任务自动存档，关掉再开回到原处；不依赖某个网页是否还活着。
  • ✓
    工具真能干活不只是"聊"，能读文件、跑命令、出产物，像本地 IDE 一样顺手。
  • ✓
    代码是你的开源在 GitHub，从外观到能力都能按自己的需求改，不是被平台框死的黑盒。

常见问题

你可能想问

我的聊天记录和文件安全吗？

全部存在你本机的 ~/.config/mycode/ 目录，密钥文件权限锁到 chmod 600，不会上传到任何服务器。

需要自己申请模型 API Key 吗？

是的。MyCodex 本身不卖模型，你用自己的 DeepSeek / 通义千问等 Key，成本完全透明、可控。

支持 Windows 或手机吗？

当前为 macOS 原生应用。Windows / 移动端在路线图中，待 macOS 体验夯实后再扩展。

能接我自己的业务系统吗？

可以。代码完全开源，后续规划的可插拔集成框架让你以插件形式接入第三方 API，而非改源码。

收费吗？

MyCodex 本身免费且开源，你只需承担所用大模型 API 的调用费用。
